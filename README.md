# Rollover To Tomorrow

This Obsidian plugin rolls unfinished tasks from today's daily note into tomorrow's daily note.

It automatically finds Markdown headings containing the word `task` or `tasks`, regardless of heading level, capitalization, emoji, or punctuation. A heading selected in the plugin settings is preferred. If that heading is missing, the first detected task heading is used.

## Attribution
